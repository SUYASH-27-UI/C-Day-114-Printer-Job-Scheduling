# C Day 114 – Printer Job Scheduling System

## Project Description
A C-based printer job scheduling simulator using the Circular Queue data structure.

## Features
- Add new print jobs.
- Assign unique job IDs.
- Process jobs in FIFO order.
- Display pending print jobs.
- Handle full and empty queue conditions.
- Reuse available queue positions.

## Technologies Used
- C Programming
- Structures
- Arrays
- Circular Queue
- Functions

## Data Structure
The project implements a Circular Queue with a fixed capacity of five jobs.

## How to Run
Compile:
`gcc printer.c -o printer`

Run:
`./printer`

## Learning Outcomes
Learned FIFO operations, circular array indexing, enqueue, dequeue, and queue overflow and underflow handling.
